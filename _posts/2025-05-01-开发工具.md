# 前言

工欲善其事，必先利其器。作为一个程序员，在工作和日常开发中，避免不了配置环境、下载各种软件包，为方便后续配置，在此记录相关环境配置经历。

# HomeBrew

常用命令：

```bash
# 1. 安装软件（核心）
brew install 软件名  # 比如 brew install mysql、brew install mysql@8.4

# 2. 卸载软件
brew uninstall 软件名  # 比如 brew uninstall mysql@8.4

# 3. 查看已安装的软件
brew list  # 列出所有已安装的包
brew list | grep mysql  # 只看和 mysql 相关的包（筛选）

# 4. 查看软件的详细信息（版本、安装路径、依赖等）
brew info 软件名  # 比如 brew info mysql

# 5. 更新 brew 自身
brew update

# 6. 更新已安装的软件
brew upgrade 软件名  # 更新指定软件，比如 brew upgrade mysql
brew upgrade  # 更新所有可更新的软件

# 7. 管理后台服务（比如 MySQL、Redis 等）
brew services start 软件名  # 启动服务并设置开机自启（比如 brew services start mysql）
brew services run 软件名 # 启动 MySQL 后台服务（无开机自启）
brew services stop 软件名   # 停止服务
brew services restart 软件名 # 重启服务
brew services list          # 查看所有 brew 管理的服务状态（能看到 mysql 是否在运行）
brew services unload 软件名 # 关闭服务的"开机自启"（仅停止自启，不停止当前运行的服务）

# 8. 清理无用的缓存和旧版本
brew cleanup  # 清理所有缓存/旧版本
brew cleanup mysql  # 只清理 mysql 相关的缓存/旧版本
```

# MySQL

## 1. 安装MySQL

- 安装命令:

    ```bash
    brew install mysql
    ```

- 安装指定版本

    ```bash
    brew install mysql@8.0
    ```

- 查看mysql版本命令:

    ```bash
    brew search mysql
    ```

## 2. 初始化配置

- 首先把mysql配置到环境变量中：

    ```bash
    echo 'export PATH="/opt/homebrew/opt/mysql@8.0/bin:$PATH"' >> ~/.lh_profile
    ```

- 启动mysql服务：

    ```bash
    brew services start mysql@8.0
    ```

- 检查mysql状态

    ```bash
    brew services list | grep mysql
    ```

    此时多次重启mysql服务，发现mysql的状态一直无法启动，状态一直是stopped。查看mysql目录下的日志发现错误信息：

    ```
    [ERROR] [MY-014061] [InnoDB] Invalid MySQL server downgrade: Cannot downgrade from 90300 to 80042. Downgrade is only permitted between patch releases.
    mysqld: Can't open file: 'mysql.ibd' (errno: 0 - )
    [ERROR] [MY-010334] [Server] Failed to initialize DD Storage Engine
    [ERROR] [MY-010020] [Server] Data Dictionary initialization failed.
    [ERROR] [MY-010119] [Server] Aborting
    ```

    发现是初始化的时候报错，具体原因是我之前先安装的9.3的版本，卸载的时候应该没有卸载干净，导致mysql认为出现了服务降级的问题（9.x->8.0），解决办法：清空数据目录，重新初始化mysql@8.0

    ```bash
    mysqld --initialize
    ```

    直接初始化会报错，上文报错信息中包含一个路径：`/opt/homebrew/var/mysql/`，这个路径就是mysql相关的存储位置

    - 停止mysql服务：`brew services stop mysql@8.0`
    - 先备份数据：`mv /opt/homebrew/var/mysql/ /opt/homebrew/var/mysql_beifen/`
    - 清空源数据：`rm -rf /opt/homebrew/var/mysql/`
    - 再次初始化：`mysqld --initialize`

    这次初始化成功了，并且生成了一个临时密码

- 重新启动mysql服务，并使用这个临时密码执行mysql初始化操作：`mysql_secure_installation`，输入临时密码即可

# Redis

